1) Le astrazioni di controllo permettono di astrarre sulla struttura sintattica controllo. Le strutture di controllo definiscono l'ordine in cui le singole istruzioni o gruppo di istruzioni devono essere eseguite. Il linguaggio macchina fornisce due semplici meccanismi per governare il flusso di controllo delle istruzioni singole: l'elaborazione in sequenza e il salto. Nei linguaggi di alto livello sono state introdotto strutture di controllo astratte come la selezione, in Java ad esempio:
if (cond) {
	S1
} else {
	S2
}

Possiamo specificare un'astrazione di controllo come segue: control I(FP1, ..., FPn) is S
dove I è un identificatore di un'astrazione di controllo, FP1, ..., FPn sono parametri formali e S è un'espressione di controllo che definisce un ordine di esecuzione.
Inoltre, i linguaggi di programmazione moderni mettono a disposizione dei meccanismi per gestire condizioni eccezionali, come errori aritmetici o di I/O. Quando viene sollevata un'eccezione, deve essere catturata e gestita. Un esempio di gestione delle eccezioni è il seguente:
- creare un gestore nel blocco corrente;
- se non c'è si esce dall'unità corrente e solleva l'eccezione nell'unità chiamante;
- continua a risalire le unità chiamanti fino a quando non si trova un gestore o fino a quando non si raggiunge il livello più alto.
Quando l'eccezione viene gestita si riparte dall'unità contenenten il gestore, detto modello a terminazione, oppure si esegue il comando che ha generato l'eccezione, detto modello di ripresa.
I linguaggi di programmazione utilizzano le strutture di controllo per definire un ordinamento totale sull'esecuzione dei comandi di un programma.

2) I costruttori sono crea() e aggiungi(Buffer, Valore) -> Buffer.
Declare:

Assumo: +(Intero, Intero) -> Intero

Operatore vuoto(Buffer) -> Boolean:
- vuoto(crea()) = true
- vuoto(aggiungi(B, v)) = false

Operatore rimuovi(Buffer) -> Buffer:
- rimuovi(crea()) = error
- rimuovi(aggiungi(B, v)) = if vuoto(B) then crea() else aggiungi(rimuovi(B), v)

Operatore leggiValore(Buffer) -> Valore
- leggiValore(crea()) = error
- leggiValore(aggiungi(B, v)) = if vuoto(B) then v else leggiValore(B)

Operatore rimuoviValore(Buffer, Valore) -> Buffer
- rimuoviValore(crea(), v) = error
- rimuoviValore(aggiungiValore(B, v), v') =
	if v = v' then rimuoviValore(B, v') else aggiungiValore(rimuoviValore(B, v'), v)

Operatore massimo(Buffer, Buffer, Valore) -> Buffer
- massimo(crea(), B', v) = B'
- massimo(aggiungiValore(B, v), B', v') =
	if v = v' then
		if 1 + conta(B, v') > conta(B', v') then B else B'
	else
		if conta(B, v') > conta(B', v') then B else B'

ove conta(Buffer, Valore) -> Intero:
- conta(crea, v) = 0
- conta(aggiungiValore(B, v), v') = if v = v' then 1 + conta(B, v') else conta(B, v')

Operatore uguale(Buffer, Buffer) -> Booleano:
- uguale(crea, B') = vuoto(B')
- uguale(aggiungiValore(B, v), B') =
	if coda(B') == v then uguale(B, rimuoviCoda(B'))
	else
		false
ove coda(Buffer) -> Valore:
- coda(crea) = error
- coda(aggiungiValore(B, v)) = v

e rimuoviCoda(Buffer) -> Buffer:
- rimuoviCoda(crea) = error
- rimuoviCoda(aggiungiValore(B, v)) = if vuoto(B) then crea() else B

6) Lo standard JDBC è stato progettato per essere indipendente dalla piattaforma. Per permetter ciò JDBC fornisce un driver manager che gestisce dinamicamente tutti gli oggetti driver di cui hanno bisogno le interrogazioni a database. Per aprire una connessione al database si deve creare un database URL che specifica:
- che si sta usando JDBC attraverso la stringa "jdbc";
- il sottoprotocollo ovvero il nome del driver o il nome di meccanismo di connettività al database;
- l'identificatore del database che fornisce un nome logico che viene associato ad una cartella fisica dove sono localizzate le tabelle.

Per instaurare una connessione al database bisogna seguire i seguenti passi:
- Trovare il driver JDBC tramite Class.forName("...") ma questo passo non è più obbligatorio da Java 6+.
- Configurazione della connessione al database. Si invoca il metodo statico DriverMananger.getConecction(databaseURL, username, password)
- Generare la query SQL. Stabilita la connessione con il metodo DriverManager.getConnection() è possibile utilizzare l'oggetto Connection per creare l'oggetto statement tramite il metodo createStatement(). Dopodichè si utilizza il metodo executeQuery() o executeUpdate() per eseguire la query SQL. Nel caso di executeUpdate() viene generato un iteratore ResultSet che permette di iterare sui record generati dalla query attraverso il metodo next().

public class DbAccess {
	private final String DBMS = "jdbc:mysql";
	private final String SERVER = "localhost";
	private String username = "root";
	private String password = "admin";
	private String database = "esempio";
	private final int PORT = 3306;

	private Connection conn;
	DbAccess() {
		String conn_string = DBMS + "://" + SERVER + ":" + PORT + "/" + database + "?user=" + username + "&password=" + password;
		try {
			conn = DriverManager.getConnection(conn_string);
		}
	}

	private void closeConnection() {
		conn.close();
	}

	public void query() {
		try {
			Statement s = conn.createStatement();
			ResultSet r = s.executeUpdate("SELECT matricola, stipendio FROM Dipendente");
			while (r.next()) {
				System.out.println(r.getString("matricola") + " " + r.getFloat("stipendio"));
			}
			r.close();
			s.close();
		} catch (SQLException e) {}
	}
}
